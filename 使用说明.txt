屏幕管家 1.7.1

运行环境：Windows 10/11 64 位，.NET Framework 4.x（Windows 11 通常已自带）。
双击 屏幕管家.exe，在安装 Sunshine 的被串流电脑上运行。
如果旧版正在运行，请先右键任务栏托盘图标选择“退出”，再启动新版。
新版采用圆角分组卡片、绿色滑动开关和蓝色操作按钮。
程序不需要安装第三方包，通常无需管理员权限，不修改 Sunshine 配置。

日常操作
顶部“当前屏幕排列”按 Windows 当前桌面坐标和像素比例绘制，蓝色表示主屏幕。
图中编号对应下方卡片和快捷键；悬停显示类型、坐标和显示模式。
卡片标注每个屏幕的类型、接口及左上角坐标 (X, Y)，主屏左上角为 (0, 0)。
位于主屏左侧或上方的屏幕允许出现负坐标；图示比例不代表显示器实际物理尺寸。
已关闭屏幕不占桌面位置，仅保留在卡片中。切换后的确认期间也展示实际生效的位置。
类型根据 Windows 连接方式和显示驱动识别，支持实体、内置、虚拟、无线及远程显示。
Zako Display Adapter 标为“虚拟屏幕 · Zako”，即使驱动模拟 HDMI 接口也能正确区分。
USB 间接显示且驱动未说明是否虚拟时，显示“USB / 虚拟待确认”；不会只凭型号猜测。
HDMI/DP 模拟器可能与实体屏幕报告相同接口，软件无法据此区分。
排列图用于查看；需要手动拖动调整位置时，请使用 Windows 显示设置。
1. 程序自动识别物理屏幕和当前已创建的虚拟屏幕，也可点击“刷新”。
2. 在“保护串流屏幕”下拉框选择 Sunshine 正在捕获的屏幕。
   程序无法自动判断 Sunshine 捕获哪块屏幕，默认不指定保护对象。
3. 打开需要启用的屏幕开关，关闭不需要的屏幕开关，点击“应用所选屏幕”。
   绿色代表选中，灰色代表未选中；开关选择需要点击应用后才生效。
4. 也可点“只开此屏”或“全部开启”，切换后 30 秒内点“画面正常，保留”。
5. 不确认会由独立后台进程恢复更改前的配置；主窗口关闭或崩溃后后台仍可恢复。
6. “恢复启动时配置”可恢复本次启动时仍可用的屏幕配置，也需要确认。
   已拔出的屏幕会跳过；新接入且已启用的屏幕会保留。
   每张屏幕卡片也可点击“设为主屏”；如果该屏幕未启用，会同时启用它。
7. 确认保留后自动找回离屏窗口；已有窗口看不到时，点击“找回窗口”。
   只移动标题栏无法在任何当前工作区内操作的普通应用窗口，不重排正常可见的窗口。
   最小化窗口会修正恢复位置；工具窗、其他虚拟桌面的隐藏窗口和系统桌面不处理。
   管理员运行的应用可能需要以管理员身份运行本工具才能移动。

关闭屏幕现在明确提交完整的启用屏幕集合，并核验 Windows 实际桌面是否与所选集合完全一致。
接口返回成功但屏幕仍被启用时，不再当作成功，会报错并请求恢复。
点击保留及保存配置时再次核对，防止串流软件在确认期间改回旧配置。
如果其他软件之后重新启用了屏幕，界面会刷新实际状态并提示，不会持续与其他软件抢占配置。

快捷操作
Ctrl + Alt + Shift + 1～9：将工具内对应编号屏幕设为主屏。
Ctrl + Alt + 1～9：开启/关闭工具内对应编号屏幕。
Ctrl + Alt + Shift + 0：打开工具面板。
快捷键和托盘操作也会触发确认倒计时。
编号按设备标识保存，重启后仍保留，与 Windows 显示设置中的编号不保证相同。
拔出的屏幕保留原编号，其他屏幕不会顶替它；新屏幕使用新编号。
对已拔出屏幕使用快捷键只会提示已断开，不会误操作其他屏幕。
编号超过 9 的屏幕使用面板或托盘控制。
关闭窗口会隐藏到右下角托盘，右键托盘图标可切换屏幕或退出。
Moonlight 客户端可能拦截组合键；此时使用面板按钮或托盘菜单。

“开关”的含义
这是启用/停用 Windows 显示输出，不是遥控显示器电源键，也不会卸载显卡或显示器驱动。
至少保留一块开启的屏幕。物理屏幕被停用后是否进入待机取决于显示器自身设置。
切换时携带完整坐标、分辨率、刷新率和显示时序，由程序按原排列计算拼接位置。
程序会记忆已启用屏幕的位置，重新开启时恢复；记忆保存在 %LOCALAPPDATA%\ScreenPilot\layout.xml。
首次使用建议在所有屏幕都开启且排列正确时运行本程序或点击刷新，记住完整布局。
从未记录过位置的新屏幕会采用首选模式放在已有排列右侧，再进行严格验证。
关闭主屏时，Windows 要求另一屏成为坐标原点，因此会整体平移坐标；其余屏幕相对排列不变。
重新开启原主屏会恢复原来的主屏和相对位置。
关闭中间屏幕后，左右两侧屏幕自动贴合；上下排列也会自动消除中间空隙。
仅移动需要填补空隙的屏幕组，保持顺序、分辨率和刷新率。
重新开启中间屏幕后恢复记住的完整排列；临时拼接位置不会覆盖完整布局记忆。
如果驱动不能使用记录的显示模式，程序会报错并恢复，不会自行降低刷新率。
工具不创建虚拟屏幕；虚拟驱动必须已安装并报告屏幕连接可用。

增加、减少与重新连接屏幕
屏幕数量不限定为三块，可以管理一块、两块或更多屏幕；可同时启用数量受显卡和驱动限制。
监听 Windows 设备和显示变化通知，等待变化稳定后刷新；另每 6 秒检查完整设备列表，
能够发现已连接但尚未启用的屏幕。虚拟显示器创建或移除也使用同一流程。
拔出屏幕后自动从当前列表移除，但保留其编号和完整布局记忆。
重新接入已知屏幕后继续沿用编号；之后通过本工具应用屏幕组合时使用记住的完整排列。
插拔后的实际桌面先由 Windows 决定，工具会更新显示状态，不在后台反复强制切换。
如果确认倒计时内发生插拔，会提前恢复仍连接的屏幕，并保留新接入且已启用的屏幕。
原屏幕全部拔出时保留当前可用桌面，不会为恢复旧快照关闭替代屏幕。
受保护的串流屏幕拔出后，下拉框会保留“已拔出”提示，需重新选择保护对象才能切换。
设备识别使用 Windows 显示设备路径，不按型号名称猜测；同型号的多个屏幕可分别记录。
更换接口、重装驱动或重新创建虚拟屏幕后，Windows 若分配新设备路径，会作为新屏幕加入。
旧布局文件会自动兼容，不需要删除个人配置。

Sunshine / Moonlight 配合使用
2026-10-13 串流重连兼容说明：已排查的 Foundation Sunshine v2026.717.124516 的
“自动激活指定显示器”（display_device_prep = ensure_active）在 Zako 模式中映射为无操作。
在屏幕管家关闭 Zako 后，Windows 可能记住禁用状态；下次串流创建屏幕仍未激活，导致连接失败。
该版本可改为 display_device_prep = ensure_secondary（副屏串流），由 Sunshine 在每次串流前
重新激活 Zako；保留现有实体主屏和已开启的实体屏幕，不开启原本已关闭的其他实体屏幕。
平时仍可在屏幕管家关闭串流屏幕。重新串流的激活由 Sunshine 完成，不要求屏幕管家常驻。
正在串流时关闭捕获屏幕仍会中断当前画面；结束本次会话后重新连接即可触发再次准备。
若 Moonlight 客户端有“自定义屏幕模式”，请选择跟随服务端；客户端覆盖为“无操作”或
“自动激活”可能绕过上述配置。换用其他 Sunshine 版本时，请根据该版本的实际选项核对。
配置通常位于 Sunshine 安装目录的 config\sunshine.conf；请先备份，在没有串流时修改并重载。
程序不会自动修改 Sunshine 配置。具体步骤、适用版本和验证范围见 docs\SUNSHINE.md。

Sunshine 的“捕获哪个屏幕”与 Windows 的“启用哪些屏幕”是两个不同设置。
本工具只管理后者，不保证关闭当前捕获屏幕后 Sunshine 自动改抓另一块屏幕。
若要只保留虚拟屏幕，请先在 Sunshine 中将该虚拟屏幕设为输出，并在本工具中保护它。
Sunshine 的“仅启用指定显示器串流”会自行关闭其他屏幕；“副屏串流”用于保留现有实体主屏。
不同分支及版本的配置键不同，请以安装版本的界面为准，不要为此直接关闭所有显示准备操作。
如果串流画面中断，请等待自动恢复，再尝试重新连接 Moonlight。
所有屏幕都不可用、Windows 注销/关机或驱动异常时，恢复不一定成功。
不要把本工具作为唯一的远程救援措施。

恢复与诊断
每次变更前的配置和恢复结果保存在：
%LOCALAPPDATA%\ScreenPilot\Recovery\<变更编号>\
before.xml 是带设备标识的恢复快照；restored 记录恢复结果；error.txt 记录恢复失败原因。
工具不会自动重新应用旧快照，避免插拔屏幕后恢复错误配置。
只读导出屏幕列表：屏幕管家.exe --list "完整输出路径.txt"
编译源码：powershell -ExecutionPolicy Bypass -File .\build.ps1
自检：.\ScreenPilot.Tests.exe --inspect（不切换屏幕，只创建并移回测试窗口）

“访问被拒绝”、看不到屏幕列表
1.7.1 起，布局记忆写不进去不会再中断屏幕读取：列表、排列图和开关照常显示，
状态栏会说明原因。常见原因是程序所在目录带“低完整性”标记（某些沙箱、托管或
便携目录），Windows 会以低完整性启动其中的程序，无法写入 %LOCALAPPDATA%。
处理办法（任选其一）：
1. 把 屏幕管家.exe 复制到普通文件夹，例如 C:\Tools\屏幕管家，再运行该副本。
2. 对该文件提升完整性级别：icacls "屏幕管家.exe" /setintegritylevel Medium
   之后重新启动程序；用资源管理器查看文件属性不会显示此标记。
3. 检查 %LOCALAPPDATA%\ScreenPilot 目录是否被设置为只读或缺少当前用户权限。
恢复记录也写不进去时，程序会取消本次切换，避免改了屏幕却无法自动恢复。
